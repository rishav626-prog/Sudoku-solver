# Sudoku Solver Web App

An interactive, web-based Sudoku solver built with **Python** and **Streamlit**. It uses a backtracking algorithm to find solutions for valid 9×9 Sudoku puzzles.

---

##  Features

* **Interactive 9×9 Grid:** Enter numbers directly in your browser on phone or PC.
* **Pre-Validation Checks:** Flags conflicting rows, columns, or 3×3 blocks before solving.
* **Fast Backtracking Engine:** Solves valid boards in milliseconds.
* **Sample Puzzle Loader:** Test the solver instantly with a pre-configured puzzle.

---

##  How to Use

1. Enter known numbers (`1–9`) in their cells.
2. Enter `0` or leave blank for empty squares.
3. Click ** Solve** to get the solution.
4. Click ** Load Sample** to test a puzzle, or ** Clear Board** to reset.
